# Desi Mandapam Baati Chokha Restaurant

Restaurant website built with React, TanStack Start, TypeScript and Tailwind CSS.

## Local development

Install Node.js 22 or newer, then run:

```bash
npm install
npm run dev
```

## Netlify deployment

Connect this repository to Netlify. The `netlify.toml` file defines the build command, Nitro preset, and publish directory. Netlify should publish `dist`, **not** `dist/client`.

The app uses server-side rendering, so keep the generated Netlify server functions alongside the public output. If Netlify has a manually configured publish directory, ensure it does not conflict with `netlify.toml`.

## Content

Replace illustrative images and verify opening hours, booking arrangements and contact details with the restaurant before launch.
